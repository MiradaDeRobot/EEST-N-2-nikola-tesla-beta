Unidad 4.3: Configuración de Redes Domésticas y SOHO

Módulo 4: Redes Informáticas para el Técnico

1. El Router Doméstico: El Centro de Mando

La configuración de una red doméstica o de pequeña oficina (SOHO - Small Office/Home Office) gira en torno a un dispositivo central: el router. Este equipo multifunción es el responsable de gestionar toda la conectividad, tanto interna como externa.

Accediendo a la Interfaz de Configuración

Para configurar un router, necesitas acceder a su panel de administración a través de un navegador web. Para ello, primero debes conocer su dirección IP, también conocida como la Puerta de Enlace Predeterminada (Default Gateway).

¿Cómo encontrar la Puerta de Enlace?

  1. En Windows, abre el Símbolo del sistema (CMD) y escribe el comando: ipconfig. Busca la dirección IP que aparece en "Puerta de enlace predeterminada".
  2. Las direcciones más comunes son 192.168.1.1 o 192.168.0.1.
  3. Introduce esa dirección IP en la barra de direcciones de tu navegador.
  4. El router te pedirá un usuario y una contraseña. Si nunca los has cambiado, estos datos suelen estar en una pegatina en la parte inferior del propio router (ej. Usuario: admin, Contraseña: admin o password).

2. Configuraciones Esenciales del Router

Una vez dentro del panel de administración, hay varias configuraciones clave que todo técnico debe conocer.

Configuración de la Red Inalámbrica (Wi-Fi)

  • SSID (Nombre de la Red): Es el nombre con el que aparecerá tu red Wi-Fi. Cámbialo por uno personalizado y evita usar información personal.
  • Seguridad y Contraseña: Es la configuración más importante. Utiliza siempre el protocolo de seguridad WPA2 o, si está disponible, WPA3. Establece una contraseña fuerte que combine letras mayúsculas, minúsculas, números y símbolos.
  • Canal: Las redes Wi-Fi operan en diferentes canales. Si vives en una zona con muchas redes vecinas, puede haber interferencias. Usar una app de "Wi-Fi Analyzer" en tu celular te puede ayudar a encontrar el canal menos congestionado.

Configuración de DHCP

El DHCP (Dynamic Host Configuration Protocol) es el servicio que asigna automáticamente una dirección IP a cada dispositivo que se conecta a la red. En la configuración del router, puedes definir el rango de direcciones IP que el servidor DHCP puede asignar (ej. desde 192.168.1.100 hasta 192.168.1.150).

Seguridad del Router

¡Cambia la Contraseña de Administrador!

Es fundamental cambiar la contraseña por defecto para acceder al panel de configuración del router. Dejar la contraseña "admin" es una gran vulnerabilidad de seguridad.

3. Solución de Problemas Comunes de Conectividad

Como técnico, te enfrentarás constantemente a problemas de conectividad. Aquí te mostramos cómo abordar los más habituales.

Problema: "No tengo Internet"

  1. Revisa los LEDs del Router: Verifica que las luces de Encendido, WAN (o Internet) y Wi-Fi/LAN estén encendidas y, en algunos casos, parpadeando.
  2. Revisa el Cableado: Asegúrate de que el cable que viene del proveedor de Internet esté bien conectado al puerto WAN del router.
  3. La Regla de Oro: Reinicia Todo. Apaga el router y tu computadora. Espera 30 segundos. Enciende primero el router, espera a que todas sus luces se estabilicen y luego enciende tu computadora. Esto soluciona un sorprendente número de problemas.
  4. Prueba con Otros Dispositivos: ¿Tu celular se puede conectar al Wi-Fi y navegar? Si es así, el problema está en tu PC. Si ningún dispositivo funciona, el problema probablemente es de tu proveedor de Internet.

Problema: "El Wi-Fi es muy lento o se corta"

  1. Ubicación del Router: El router debe estar en una ubicación céntrica de la casa, en un lugar elevado y lejos de obstrucciones metálicas o muros gruesos.
  2. Interferencia de Canales: Como se mencionó antes, usa un analizador de Wi-Fi para encontrar un canal menos saturado.
  3. Distancia: La señal Wi-Fi se debilita con la distancia. Si estás muy lejos, considera usar un repetidor Wi-Fi o un sistema de red en malla (Mesh).
  4. Diferencia entre 2.4 GHz y 5 GHz: La banda de 2.4 GHz tiene más alcance pero es más lenta y susceptible a interferencias. La banda de 5 GHz es mucho más rápida pero tiene menos alcance. Conéctate a la banda de 5 GHz siempre que sea posible.
