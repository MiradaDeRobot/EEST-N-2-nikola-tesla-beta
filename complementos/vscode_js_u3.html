Unidad 3: JavaScript - Añadiendo Interactividad

Desarrollo Web con Visual Studio Code

1. ¿Qué es JavaScript? El Cerebro de la Web

JavaScript (JS) es un lenguaje de programación que permite implementar funciones complejas en las páginas web. Mientras que HTML estructura el contenido y CSS le da estilo, JavaScript añade la interactividad. Es el lenguaje que se encarga de que las cosas sucedan: desde simples alertas y animaciones hasta complejas aplicaciones web que reaccionan a las acciones del usuario en tiempo real.

2. Fundamentos del Lenguaje: La Gramática de JS

Antes de manipular una página, es crucial entender los conceptos básicos del lenguaje.

Variables

Son contenedores para almacenar datos. Se declaran con let (para variables que pueden cambiar) o const (para constantes que no cambiarán).

let edad = 25;
const nombre = "Nikola";

Condicionales (if/else)

Permiten que tu código tome decisiones y ejecute diferentes bloques de código según una condición.

if (edad >= 18) {
    console.log("Es mayor de edad.");
} else {
    console.log("Es menor de edad.");
}

Funciones

Son bloques de código reutilizables que realizan una tarea específica. Se definen con la palabra clave function.

function saludar(nombre) {
    return "Hola, " + nombre;
}

// Para usarla:
let saludo = saludar("Tesla"); // saludo ahora contiene "Hola, Tesla"

3. El DOM: El Puente entre HTML y JavaScript

El DOM (Document Object Model) es la habilidad más importante que aprenderás en JavaScript para la web. Es una representación de tu documento HTML en forma de árbol de objetos. JavaScript puede leer y modificar este árbol, lo que le permite cambiar el contenido, la estructura y el estilo de la página dinámicamente.

Seleccionar y Manipular Elementos

Pasos para la Manipulación:

  1. Seleccionar un elemento: Primero, necesitas "atrapar" el elemento HTML que quieres manipular.
    • document.getElementById('id-del-elemento'): Selecciona un elemento por su ID.
    • document.querySelector('.clase-del-elemento'): Selecciona el primer elemento que coincida con un selector de CSS.
  2. Manipularlo: Una vez seleccionado, puedes cambiar sus propiedades.
    • elemento.innerHTML = "Nuevo contenido";: Cambia el contenido HTML interno.
    • elemento.style.color = "red";: Cambia sus estilos CSS.
    • elemento.classList.add('nueva-clase');: Añade una clase de CSS.

4. Proyecto Guiado: Creando un Interruptor de Modo Oscuro

Vamos a añadir interactividad a nuestra página de biografía. Crearemos un botón que permita al usuario cambiar entre un tema claro y uno oscuro.

Paso 1: Modificar el HTML (biografia.html)

Añade un botón en el <header> y enlaza un nuevo archivo JavaScript justo antes de cerrar el </body>.

...
<header>
    <h1>Nikola Tesla: El Genio de la Electricidad</h1>
    <button id="modo-oscuro-btn">Activar Modo Oscuro</button>
</header>
...
<script src="script.js"></script>
</body>
</html>

Paso 2: Añadir Estilos para el Modo Oscuro (estilos.css)

Añade al final de tu archivo CSS una nueva clase que definirá los colores del modo oscuro.

...
/* Añadir al final de estilos.css */
body.modo-oscuro {
    background-color: #1a1a1a;
    color: #f4f4f4;
}

main.modo-oscuro {
    background-color: #2a2a2a;
    box-shadow: 0 0 10px rgba(255,255,255,0.1);
}

.modo-oscuro h1, .modo-oscuro h2 {
    color: #2dd4bf; /* Un teal brillante */
}

Paso 3: Crear la Lógica en JavaScript (script.js)

Crea un nuevo archivo llamado script.js. Este código seleccionará el botón y el cuerpo de la página, y añadirá la funcionalidad de cambiar las clases.

// 1. Seleccionar los elementos que necesitamos
const botonModoOscuro = document.getElementById('modo-oscuro-btn');
const body = document.querySelector('body');
const main = document.querySelector('main');

// 2. Crear la función que cambiará los estilos
function cambiarModoOscuro() {
    // toggle() añade la clase si no está, y la quita si ya está
    body.classList.toggle('modo-oscuro');
    main.classList.toggle('modo-oscuro');
    
    // Cambiar el texto del botón
    if (body.classList.contains('modo-oscuro')) {
        botonModoOscuro.innerHTML = "Activar Modo Claro";
    } else {
        botonModoOscuro.innerHTML = "Activar Modo Oscuro";
    }
}

// 3. Escuchar el evento 'click' en el botón
botonModoOscuro.addEventListener('click', cambiarModoOscuro);

¡Listo! Guarda los tres archivos. Ahora, cuando abras tu página y hagas clic en el botón, verás cómo los estilos cambian gracias a la magia de JavaScript.
