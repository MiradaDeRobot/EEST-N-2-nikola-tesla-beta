Unidad 2: CSS - Dando Estilo a la Web

Desarrollo Web con Visual Studio Code

1. ¿Qué es CSS? La Ropa de la Web

CSS (Cascading Style Sheets), u Hojas de Estilo en Cascada, es el lenguaje que usamos para definir el estilo y la presentación visual de un documento HTML. Si HTML es el esqueleto de una página, CSS es la piel, la ropa y el maquillaje. Se encarga de todo lo visual: colores, fuentes, espaciado, posicionamiento y animaciones.

2. Sintaxis y Selectores: Cómo Apuntar a los Elementos

Para aplicar un estilo, primero necesitas decirle a CSS a qué elemento HTML quieres aplicárselo. Esto se hace mediante selectores.

La Regla CSS Básica

selector {
    propiedad: valor;
}

/* Ejemplo: Hacer que todos los párrafos (
) tengan texto azul */
p {
    color: blue;
}

Selectores Fundamentales:

  • Selector de Etiqueta: Selecciona todas las etiquetas de un tipo. Ejemplo: h1 selecciona todos los títulos h1.
  • Selector de Clase: Selecciona todos los elementos que tengan un atributo class específico. Se define con un punto. Ejemplo: .destacado selecciona todos los elementos con class="destacado".
  • Selector de ID: Selecciona un único elemento que tenga un atributo id específico. Se define con una almohadilla (#). El ID debe ser único en toda la página. Ejemplo: #titulo-principal.

3. Catálogo de Propiedades CSS Esenciales

Aquí tienes una lista de las propiedades CSS más comunes, divididas por categoría, para empezar a dar estilo a tus páginas.

Colores y Fondos

color: blue;: Cambia el color del texto.
background-color: #f0f0f0;: Cambia el color de fondo.
background-image: url('imagen.jpg');: Establece una imagen de fondo.

Tipografía

font-family: Arial, sans-serif;: Define la fuente.
font-size: 16px;: Define el tamaño del texto.
font-weight: bold;: Define el grosor del texto (normal, bold).
text-align: center;: Alinea el texto (left, center, right).
text-decoration: none;: Quita o añade decoraciones como el subrayado de los enlaces.
line-height: 1.5;: Define el espacio entre líneas de texto.

El Modelo de Caja (Box Model)

width: 500px;: Define el ancho del contenido.
height: 300px;: Define el alto del contenido.
padding: 10px;: Añade un relleno interior.
border: 1px solid black;: Añade un borde.
margin: 20px;: Añade un margen exterior.
border-radius: 15px;: Redondea las esquinas del borde.

Layout y Posicionamiento

Display: display: block; (ocupa todo el ancho disponible), display: inline; (ocupa solo el espacio necesario), display: flex; (activa el modelo de caja flexible para alinear elementos fácilmente).
Position: position: relative; (se puede mover respecto a su posición original), position: absolute; (se posiciona respecto a su contenedor padre más cercano que no sea estático).

Pseudo-clases: Estilos Interactivos

Las pseudo-clases permiten aplicar estilos a un elemento en un estado especial, como cuando el ratón está sobre él.

a:hover { color: red; }
Este código hace que cualquier enlace (<a>) cambie su color a rojo cuando el usuario pasa el ratón por encima (:hover).

4. Proyecto Guiado: Dando Estilo a Nuestra Biografía

Tomaremos el HTML de la biografía de Nikola Tesla de la unidad anterior y le daremos vida con CSS.

Paso 1: Crear y Enlazar el Archivo CSS

En VS Code, crea un nuevo archivo en la misma carpeta que tu HTML y llámalo estilos.css. Luego, añade la siguiente línea dentro del <head> de tu archivo HTML para enlazarlo:

<link rel="stylesheet" href="estilos.css">

Paso 2: Añadir los Estilos en estilos.css

/* Estilos generales para toda la página */
body {
    font-family: sans-serif;
    line-height: 1.6;
    margin: 0;
    padding: 20px;
    background-color: #f4f4f4;
    color: #333;
}

/* Estilos para el contenedor principal */
main {
    max-width: 800px;
    margin: auto;
    background: white;
    padding: 20px;
    border-radius: 8px;
    box-shadow: 0 0 10px rgba(0,0,0,0.1);
}

/* Estilos para los títulos */
h1, h2 {
    color: #0f766e; /* Un tono de teal */
}

h1 {
    text-align: center;
    margin-bottom: 20px;
}

h2 {
    border-bottom: 2px solid #2dd4bf;
    padding-bottom: 5px;
}

/* Estilos para la imagen */
img {
    max-width: 100%;
    height: auto;
    display: block;
    margin: 20px auto;
    border-radius: 8px;
}

/* Estilos para el pie de página y los enlaces */
footer {
    text-align: center;
    margin-top: 30px;
    font-size: 0.9em;
    color: #666;
}

a {
    color: #0d9488;
    text-decoration: none; /* Quita el subrayado por defecto */
}

a:hover {
    text-decoration: underline; /* Añade el subrayado al pasar el ratón */
}

¡Guarda ambos archivos y abre tu biografia.html en el navegador para ver el resultado! Notarás cómo la página ha pasado de ser un simple texto negro sobre blanco a un diseño estructurado y agradable a la vista.
