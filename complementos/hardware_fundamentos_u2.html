Unidad 1.2: La Placa Madre (Motherboard)

Módulo 1: Fundamentos del Hardware

1. ¿Qué es la Placa Madre? El Centro de Conexiones

La Placa Madre (o Motherboard) es el componente más fundamental de una computadora. Es un gran circuito impreso que actúa como una plataforma central, conectando todos los componentes principales del sistema entre sí. Piensa en ella como el sistema nervioso y esquelético de la PC: proporciona tanto el soporte físico como las vías de comunicación para que la CPU, la RAM, el almacenamiento y la GPU puedan trabajar juntos.

Funciones Clave

  • Interconexión de Componentes: Proporciona los zócalos y ranuras para instalar la CPU, la memoria RAM y las tarjetas de expansión.
  • Distribución de Energía: Recibe la energía de la fuente de alimentación y la distribuye de forma regulada a todos los componentes conectados a ella.
  • Comunicación de Datos: A través de sus circuitos (llamados "buses"), permite que los componentes intercambien datos a altas velocidades.
  • Interfaz con Periféricos: Incluye los puertos de E/S (Entrada/Salida) para conectar dispositivos externos como teclados, ratones, monitores y unidades USB.

2. Formatos de Placa Madre (Factor de Forma)

El "factor de forma" se refiere al tamaño y la disposición física de la placa madre. Determina el tipo de gabinete que se puede usar y la cantidad de ranuras de expansión disponibles.

ATX (Advanced Technology eXtended)

Es el estándar para las PC de escritorio. Ofrece el mayor número de ranuras de expansión (PCIe) y ranuras de RAM, ideal para equipos de alto rendimiento y gaming.

Micro-ATX

Una versión más corta que la ATX, con menos ranuras de expansión. Es un formato muy popular por su equilibrio entre tamaño y funcionalidad, ideal para computadoras compactas pero potentes.

Mini-ITX

Es el formato más pequeño, diseñado para sistemas de cine en casa (HTPC) o computadoras de muy bajo perfil. Típicamente solo tiene una ranura de expansión para una tarjeta gráfica.

3. Componentes Detallados de la Placa Madre

Vamos a desglosar las partes más importantes que encontrarás en cualquier placa madre moderna.

Zócalo del CPU (Socket)

Es el conector donde se instala el procesador. Cada familia de procesadores tiene un tipo de zócalo específico (ej. LGA 1700 para Intel, AM5 para AMD). Es el primer factor de compatibilidad a considerar.

Ranuras de RAM (DIMM Slots)

Aquí es donde se instalan los módulos de memoria RAM. La mayoría de las placas ATX tienen 4 ranuras, mientras que las Mini-ITX suelen tener 2. Soportan configuraciones de doble canal (Dual Channel) para un mayor rendimiento.

Puertos de Expansión (PCIe)

Las ranuras PCI Express (PCIe) se usan para conectar tarjetas de expansión. La más importante es la ranura PCIe x16 (la más larga y reforzada), donde se instala la tarjeta gráfica. Otras ranuras más pequeñas (x1, x4) se usan para tarjetas de sonido, de red o de captura de video.

Chipset

Es un conjunto de circuitos integrados (generalmente cubierto por un disipador de calor) que actúa como el "director de tráfico" de la placa madre. Gestiona el flujo de datos entre la CPU, la RAM, los puertos de expansión y los periféricos.

4. El BIOS/UEFI: El Arranque del Sistema

El BIOS (Basic Input/Output System) o su sucesor moderno, UEFI (Unified Extensible Firmware Interface), es el firmware de la placa madre. Es el primer software que se ejecuta al encender la PC.

Funciones y Configuración

Funciones Principales:

  • POST (Power-On Self-Test): Realiza una autocomprobación de todo el hardware principal (CPU, RAM, GPU) al arrancar para asegurarse de que funciona correctamente.
  • Inicialización de Hardware: Prepara los componentes para que el sistema operativo pueda tomarlos.
  • Carga del Sistema Operativo: Busca el sistema operativo en una unidad de almacenamiento y le cede el control de la computadora.

Configuraciones Comunes:

Se accede al UEFI/BIOS presionando una tecla específica durante el arranque (generalmente Supr, F2, o F12). Dentro, puedes configurar:

  • El orden de arranque de los dispositivos (boot order).
  • La fecha y hora del sistema.
  • Activar perfiles de memoria RAM (XMP/EXPO) para que funcionen a su máxima velocidad.
  • Monitorizar temperaturas y voltajes.
  • Configuraciones de overclocking (para usuarios avanzados).
