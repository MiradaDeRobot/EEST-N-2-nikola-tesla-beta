Unidad 3: Sensores, Datos y Proyectos Completos

Creación de Apps con App Inventor

1. Interactuando con el Mundo Real: Los Sensores

La verdadera magia de las aplicaciones móviles reside en su capacidad para interactuar con el entorno a través de los sensores del teléfono. App Inventor facilita enormemente el acceso a estos componentes de hardware.

Sensores Comunes y sus Bloques

Para usar un sensor, simplemente arrástralo desde la Paleta (sección "Sensors") al Visor. Son componentes no visibles, por lo que aparecerán en la parte inferior de la pantalla.

Acelerómetro (AccelerometerSensor)

Detecta el movimiento y la agitación del teléfono. Su evento principal es when AccelerometerSensor.Shaking (cuando se agita el teléfono).

Sensor de Ubicación (LocationSensor)

Proporciona datos del GPS del teléfono. Su evento clave es when LocationSensor.LocationChanged, que se activa cuando el teléfono detecta una nueva ubicación y te da la latitud, longitud y altitud.

Texto a Voz (TextToSpeech)

Un componente de la paleta "Media" que convierte texto en voz. Su bloque principal es el método call TextToSpeech.Speak, que lee en voz alta el texto que le pases.

Cámara (Camera)

Permite acceder a la cámara del teléfono para tomar fotos. Usas el método call Camera.TakePicture y, una vez que el usuario toma la foto, se activa el evento when Camera.AfterPicture, que te devuelve la imagen capturada.

2. Guardando Datos: La Base de Datos TinyDB

Por defecto, los datos en una aplicación (como el texto en una etiqueta) se pierden cuando se cierra. Para guardar información de forma permanente en el dispositivo, App Inventor ofrece un componente muy simple llamado TinyDB.

Funcionamiento Clave-Valor

TinyDB funciona como un pequeño diccionario. Guardas un dato (el valor) asociándolo con una etiqueta única (la clave o "tag"). Luego, puedes recuperar ese dato usando la misma clave.

Guardar un Dato (StoreValue)

El bloque call TinyDB1.StoreValue necesita dos argumentos: una tag (ej. "ultimaUbicacion") y el valueToStore (el dato que quieres guardar).

Recuperar un Dato (GetValue)

El bloque call TinyDB1.GetValue necesita la tag del dato que quieres recuperar y un valueIfTagNotThere (el valor que devolverá si no encuentra nada guardado con esa clave).

3. Proyecto Guiado: App "¿Dónde Estoy?"

Vamos a construir una aplicación que utiliza el GPS para mostrar tu ubicación actual, la lee en voz alta y la guarda para la próxima vez que abras la app.

Paso 1: Diseño de la Interfaz

  1. Arrastra 3 Etiquetas: una para la latitud, una para la longitud y una para la dirección. Cambia sus textos iniciales.
  2. Arrastra un Botón con el texto "Obtener Ubicación".
  3. Desde la Paleta "Sensors", arrastra un LocationSensor.
  4. Desde "Media", arrastra un TextToSpeech.
  5. Desde "Storage", arrastra una TinyDB.

Paso 2: Programación de la Lógica (Vista de Bloques)

  1. Cuando cambia la ubicación: Usa el evento when LocationSensor1.LocationChanged. Dentro, actualiza el texto de las etiquetas de latitud y longitud con los valores que proporciona el evento (get latitude y get longitude).
  2. Convertir a Dirección: Dentro del mismo evento, usa el método call LocationSensor1.LatitudeToAddress y LongitudeToAddress para obtener la dirección.
  3. Cuando se obtiene la dirección: App Inventor tiene un evento especial para esto. Usa when LocationSensor1.AddressChanged. Dentro, actualiza la etiqueta de dirección con el valor get address.
  4. Leer en Voz Alta y Guardar: Dentro del evento AddressChanged, añade el bloque call TextToSpeech1.Speak con el get address. Inmediatamente después, añade el bloque call TinyDB1.StoreValue para guardar la dirección con la clave "ultimaDireccion".
  5. Cargar al Iniciar: Usa el evento when Screen1.Initialize (que se ejecuta al abrir la app). Dentro, pon el texto de la etiqueta de dirección al valor que obtienes con call TinyDB1.GetValue, usando la clave "ultimaDireccion".
