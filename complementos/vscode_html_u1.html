Unidad 1: HTML - La Estructura de la Web

Desarrollo Web con Visual Studio Code

1. ¿Qué es HTML y por qué es fundamental?

HTML (HyperText Markup Language), o Lenguaje de Marcado de Hipertexto, es el lenguaje estándar utilizado para crear y estructurar el contenido de las páginas web. No es un lenguaje de programación, sino un lenguaje de marcado. Su trabajo es decirle al navegador cómo debe organizar el contenido, como "esto es un título", "esto es un párrafo" o "aquí va una imagen". HTML es el esqueleto sobre el que se construye toda la web.

2. La Estructura de un Documento HTML

Todo archivo HTML sigue una estructura básica y predecible que el navegador entiende. Esta estructura se define mediante etiquetas (tags).

La Plantilla Esencial

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de mi Página</title>
</head>
<body>
    <!-- El contenido visible de la página va aquí -->
</body>
</html>

Desglose de la Estructura:

  • <!DOCTYPE html>: Declara que el documento es de tipo HTML5.
  • <html>: Es la etiqueta raíz que envuelve todo el contenido.
  • <head>: Contiene "metadatos" sobre la página que no son visibles directamente, como el título que aparece en la pestaña del navegador (<title>), la codificación de caracteres (<meta charset="UTF-8">) y enlaces a archivos de estilo (CSS) o scripts (JavaScript).
  • <body>: Contiene todo el contenido visible de la página web: texto, imágenes, videos, enlaces, etc.

3. Catálogo de Etiquetas Imprescindibles

El contenido se estructura mediante etiquetas. Aquí tienes un catálogo de las más utilizadas, divididas por función.

Texto y Contenido

<h1> a <h6>: Definen títulos, del más importante (h1) al menos importante (h6).
<p>: Define un párrafo de texto.
<strong>: Marca un texto como importante (se ve en negrita).
<em>: Pone énfasis en un texto (se ve en cursiva).
<br>: Inserta un salto de línea.
<hr>: Inserta una línea horizontal para separar temas.

Enlaces y Multimedia

Enlaces: <a href="https://www.google.com">Ir a Google</a>
Crea un hipervínculo a otra página.
Imágenes: <img src="foto.jpg" alt="Descripción de la foto">
Inserta una imagen. El atributo `alt` es crucial para la accesibilidad.
Video: <video src="video.mp4" controls></video>
Inserta un video. El atributo `controls` añade los controles de reproducción.
Audio: <audio src="audio.mp3" controls></audio>
Inserta un archivo de audio con controles.

Listas

<ul> <!-- Lista no ordenada -->
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ul>
<ol> <!-- Lista ordenada -->
  <li>Primer paso</li>
  <li>Segundo paso</li>
</ol>

Tablas

<table>
  <tr> <!-- Fila -->
    <th>Encabezado 1</th> <!-- Celda de encabezado -->
    <th>Encabezado 2</th>
  </tr>
  <tr>
    <td>Dato 1</td> <!-- Celda de datos -->
    <td>Dato 2</td>
  </tr>
</table>

Contenedores y Estructura Semántica

<div>: Un contenedor genérico en bloque. Se usa para agrupar grandes secciones de contenido para aplicarles estilos con CSS.
<span>: Un contenedor genérico en línea. Se usa para agrupar pequeñas partes de texto dentro de un párrafo.

Recuerda también las etiquetas semánticas: <header>, <nav>, <main>, <section>, <article>, y <footer>.

4. Proyecto Guiado: Creando una Página de Biografía Simple

Vamos a aplicar todo lo aprendido para crear una página web completa desde cero en Visual Studio Code.

Resultado Final:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Biografía de Nikola Tesla</title>
</head>
<body>

    <header>
        <h1>Nikola Tesla: El Genio de la Electricidad</h1>
    </header>

    <main>
        <section>
            <h2>¿Quién fue Nikola Tesla?</h2>
            <p>
                Nikola Tesla (1856-1943) fue un inventor, ingeniero eléctrico y mecánico serbio-estadounidense, 
                famoso por sus contribuciones al diseño del sistema de suministro de energía eléctrica de 
                corriente alterna (AC) moderno.
            </p>
            <img src="https://placehold.co/600x400/F1F5F9/1E3A8A?text=Retrato+de+Nikola+Tesla" alt="Un retrato de Nikola Tesla">
        </section>

        <section>
            <h2>Inventos y Contribuciones Clave</h2>
            <ul>
                <li>Motor de Corriente Alterna</li>
                <li>Bobina de Tesla</li>
                <li>Radio (aunque a menudo se atribuye a Marconi)</li>
            </ul>
        </section>
    </main>

    <footer>
        <p>Para saber más, puedes visitar su página en <a href="https://es.wikipedia.org/wiki/Nikola_Tesla">Wikipedia</a>.</p>
    </footer>

</body>
</html>

Para ver este proyecto, simplemente guarda el código anterior en un archivo llamado biografia.html y ábrelo con tu navegador web.
