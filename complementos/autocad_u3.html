Unidad 3: Preparación de Planos y Trazado (Ploteo)

AutoCAD para Planos Técnicos

1. Del Dibujo al Plano: Espacio Modelo y Espacio Papel

Hasta ahora, hemos trabajado en el Espacio Modelo, un universo digital infinito donde dibujamos nuestros diseños a escala real (1:1). Sin embargo, un plano profesional requiere un formato de hoja, un rótulo (cajetín), márgenes y escalas de impresión. Todo esto se gestiona en el Espacio Papel, también conocido como Layout (Presentación).

La Diferencia Fundamental

Espacio Modelo (Model Space)

Es donde se crea la geometría de tu diseño. Se dibuja siempre a tamaño real, sin preocuparse por el tamaño del papel. Es tu taller de dibujo.

Espacio Papel (Layout)

Es una hoja virtual que representa el papel en el que vas a imprimir. Aquí no se dibuja el objeto, sino que se insertan "ventanas" (viewports) que muestran vistas de tu Espacio Modelo. Es tu sala de presentación.

2. Configuración de la Página (Page Setup)

Antes de empezar a organizar el plano, debemos definir las propiedades de nuestra hoja de papel virtual.

El Administrador de Configuraciones de Página

Haz clic derecho en una de las pestañas de Layout en la parte inferior y selecciona "Page Setup Manager". Aquí defines:

  • Impresora/Trazador (Printer/Plotter): Selecciona la impresora que vas a usar o, lo más común, una impresora virtual como DWG to PDF.pc3 para crear un archivo PDF.
  • Tamaño de Papel (Paper Size): Elige el formato de hoja normalizado que necesites (ej. A4, A3).
  • Área de Trazado (Plot Area): Generalmente se deja en "Layout" para que imprima toda la hoja.
  • Tabla de Estilos de Trazado (Plot Style Table): Aquí es donde defines cómo se imprimirán los colores. Para planos técnicos, se suele usar monochrome.ctb, que imprime todo en negro, respetando los grosores de línea definidos en las capas.

3. Ventanas Gráficas (Viewports): Las Ventanas a tu Modelo

Una Ventana Gráfica (Viewport) es un objeto que creas en el Espacio Papel y que actúa como una ventana a través de la cual puedes ver tu dibujo del Espacio Modelo. Puedes tener múltiples viewports en una misma hoja, cada una mostrando una parte diferente de tu dibujo o la misma parte a diferentes escalas.

Creación y Configuración de una Ventana Gráfica

  1. Ve a la pestaña "Layout" en la cinta de opciones y crea un viewport rectangular.
  2. Haz doble clic dentro del viewport para "activarlo". Ahora puedes hacer zoom y encuadrar tu dibujo del Espacio Modelo como si estuvieras en él.
  3. Con el viewport activado, selecciona una escala estándar desde la barra de estado (ej. 1:1, 1:2, 1:50). Esto es crucial para que el plano esté a escala.
  4. Una vez que la vista y la escala son correctas, haz doble clic fuera del viewport para desactivarlo y bloquéalo para evitar moverlo accidentalmente.

4. El Proceso Final: Trazado (Ploteo) a PDF

Con la hoja configurada, el rótulo insertado, las vistas a escala dentro de los viewports y las cotas añadidas, el último paso es generar el archivo final para su impresión o envío.

El Comando PLOT

Ejecuta el comando PLOT (o presiona Ctrl+P). Se abrirá la ventana de trazado. Como ya hemos configurado la página en el "Page Setup Manager", la mayoría de las opciones ya estarán correctas. Simplemente haz clic en "Preview" para ver una vista previa de cómo quedará el plano. Si todo está en orden, haz clic en "OK" para generar el archivo PDF.
