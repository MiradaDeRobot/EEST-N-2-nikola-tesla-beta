Unidad 2: Capas, Bloques y Acotación

AutoCAD para Planos Técnicos

1. Capas (Layers): Organizando tu Dibujo

Las capas son el método fundamental de organización en AutoCAD. Imagina que son como hojas de acetato transparentes apiladas una sobre otra. Puedes dibujar diferentes partes de tu plano en diferentes capas (ej. una para muros, una para cotas, una para texto) y luego controlar la visibilidad y propiedades de cada capa de forma independiente.

El Administrador de Propiedades de Capas (Layer Properties Manager)

Se accede con el comando LAYER (o LA). Aquí es donde creas y gestionas todas tus capas. Cada capa tiene propiedades clave:

  • Nombre: Dale un nombre descriptivo (ej. "Ejes", "Mobiliario", "Cotas").
  • Color: Asigna un color a la capa para diferenciar visualmente los objetos.
  • Tipo de Línea (Linetype): Define si la línea es continua, de trazos, de centro, etc.
  • Grosor de Línea (Lineweight): Controla el grosor con el que se imprimirá la línea.
  • Visibilidad (On/Off/Freeze): Puedes apagar una capa (Off) para ocultarla o congelarla (Freeze) para que también se excluya de los cálculos del programa, mejorando el rendimiento.

2. Bloques (Blocks): Dibujando de Forma Eficiente

Un bloque es un conjunto de objetos que se combinan para crear un único objeto reutilizable. Son una de las herramientas más potentes para mejorar la eficiencia y mantener la consistencia en un dibujo.

Ventajas de Usar Bloques

Eficiencia y Reutilización

Dibuja un objeto una sola vez (como un tornillo, una silla o un símbolo eléctrico) y guárdalo como un bloque. Luego puedes insertarlo tantas veces como necesites.

Fácil Actualización

Si editas la definición del bloque, todas las inserciones de ese bloque en el dibujo se actualizan automáticamente. Si tienes 100 tornillos iguales y necesitas cambiar su tamaño, solo editas el bloque una vez.

Creación e Inserción de Bloques

  • Crear un Bloque (BLOCK): Dibuja la geometría que quieres convertir en bloque. Ejecuta el comando BLOCK, dale un nombre, selecciona un punto base para su inserción y selecciona los objetos que lo componen.
  • Insertar un Bloque (INSERT): Ejecuta el comando INSERT para abrir una galería con todos los bloques definidos en tu dibujo. Selecciona el que quieres y colócalo en tu plano.

3. Acotación (Dimensioning): Documentando tu Diseño

La acotación es el proceso de añadir las medidas al dibujo. Un plano técnico sin cotas es solo un dibujo; con cotas, se convierte en un documento de fabricación o construcción.

Comandos de Acotación Principales

  • DIMLINEAR: Crea cotas horizontales o verticales.
  • DIMALIGNED: Crea cotas alineadas a un objeto inclinado.
  • DIMRADIUS / DIMDIAMETER: Crean cotas de radio y diámetro para círculos y arcos.
  • DIMANGULAR: Crea cotas para medir el ángulo entre dos líneas.

Estilos de Cota (Dimension Styles)

Con el comando DIMSTYLE (o D), puedes abrir el administrador de estilos de cota. Aquí puedes personalizar cada aspecto de tus cotas: el tamaño del texto, el tipo de flecha, el color de las líneas, las unidades y la precisión, para que se ajusten a las normas de dibujo técnico.
