Unidad 3: Visualización 3D y Generación de Gerbers

Diseño y Simulación con Proteus

1. Visualización 3D: Dando Vida a tu Diseño

Antes de enviar un diseño a fabricar, es fundamental tener una idea clara de cómo se verá el producto final. El Visualizador 3D (3D Visualizer) de ARES es una herramienta increíblemente potente que genera una representación tridimensional y fotorrealista de tu PCB, con todos los componentes montados.

La Importancia de la Vista Previa 3D

Esta herramienta no es solo estética, es una parte crucial del proceso de verificación del diseño. Te permite:

  • Verificar la Colocación: Comprobar si los componentes están correctamente orientados y si hay suficiente espacio entre ellos.
  • Detectar Colisiones: Asegurarse de que componentes altos (como capacitores electrolíticos) no choquen entre sí o con otros elementos.
  • Revisar la Serigrafía (Silkscreen): Verificar que los nombres y valores de los componentes sean legibles y no estén tapados por otros componentes.
  • Presentar el Proyecto: Generar imágenes de alta calidad para la documentación o presentación del proyecto.

2. Archivos Gerber: El Lenguaje de los Fabricantes de PCB

Cuando envías un diseño a un fabricante profesional de PCBs, no le envías el archivo de Proteus. Le envías un conjunto de archivos estandarizados llamados Archivos Gerber. Cada archivo Gerber es un "mapa" vectorial que describe una de las capas de la placa.

El Paquete de Fabricación Completo

Un paquete de fabricación típico incluye:

  • Archivos Gerber para cada capa de cobre: Uno para "Top Copper", otro para "Bottom Copper", etc.
  • Archivos Gerber para las máscaras de soldadura (Solder Mask): Uno para la capa superior y otro para la inferior. La máscara de soldadura es la capa de barniz (generalmente verde) que protege el cobre y deja expuestos solo los pads.
  • Archivo Gerber para la serigrafía (Silkscreen): Contiene el texto y los contornos de los componentes.
  • Archivo Excellon para las perforaciones (Drill File): Un archivo separado que indica las coordenadas y el diámetro de cada uno de los agujeros que se deben perforar en la placa.

3. Proyecto Guiado: Generando los Gerbers del Circuito Blink

Vamos a generar el paquete completo de archivos de fabricación para el PCB de nuestro Arduino Blink.

Paso 1: Abrir la Herramienta de Salida

Con tu diseño de PCB abierto en ARES, ve al menú superior Output > Generate Gerber/Excellon Files.... Se abrirá la ventana de configuración.

Paso 2: Configurar las Capas y Formato

  1. Formato: Asegúrate de que el formato seleccionado sea RS274X, que es el estándar moderno.
  2. Capas (Layers): En la pestaña "Layers", selecciona todas las capas que necesitas para la fabricación. Para una placa simple de una cara, como la nuestra, normalmente marcarías:
    • Bottom Copper (Cobre Inferior)
    • Top Silk (Serigrafía Superior)
    • Solder Mask Bottom (Máscara de Soldadura Inferior)
    • Board Edge (Contorno de la Placa)
  3. Drill File: En la pestaña "Drill", asegúrate de que la opción para generar el archivo de perforación esté activada.
  4. Carpeta de Salida: Especifica una carpeta donde se guardarán todos los archivos generados. Es una buena práctica crear una carpeta nueva llamada "Gerbers" dentro de tu proyecto.

Paso 3: Ejecutar y Verificar

Haz clic en el botón "OK". Proteus generará todos los archivos en la carpeta que especificaste. El resultado será una lista de archivos con extensiones como .GBL (Gerber Bottom Layer), .GTS (Gerber Top Silkscreen), .TXT (Drill File), etc.

Estos archivos son los que se comprimen en un archivo .zip y se envían al fabricante de PCBs. Puedes usar un visor de Gerbers online gratuito para verificar que todas las capas se han generado correctamente antes de enviarlos.
